## Start with the actual footprint

Deck material planning starts with measured length and width, but the real count depends on layout, board direction, stairs, picture framing, and waste allowance.

## Add waste on purpose

Cuts, defects, and layout decisions create waste. Planning a reasonable allowance up front is better than trying to match boards later.

## Keep your plan durable

Think through fasteners, flashing, water movement, blocking, and access before buying the visible boards. The finished surface is only as dependable as the structure below it.
