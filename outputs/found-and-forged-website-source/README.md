# Found & Forged

Mobile-first Next.js site for Found & Forged, built with Tailwind CSS, MDX blog content, static metadata, RSS, sitemap, robots, calculators, and a quote request form stub.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The quote form currently logs to the browser console. Comments in `components/QuoteForm.tsx` mark where email, database, CRM, and photo storage integrations should connect.
